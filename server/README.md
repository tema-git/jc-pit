# Обращения HJC Pit

Статические страницы на Спринтхосте и Bunny используют один адрес:
`https://forms.hjcpit.com/submit.php`. Поддомен направлен непосредственно на
Спринтхост. GeoDNS основного сайта не изменяется. PHP не публикуется на Pages/Bunny.

Размещение в `~/domains/forms.hjcpit.com/`:

- `public_html/submit.php`, `public_html/.htaccess` — из `server/public/`;
- `private/enquiry.php` — из `server/private/`;
- `private/config.php` — копия примера с `enabled => true` после настройки;
- `private/state/` создаётся обработчиком с правами 0700, файлы — 0600.

Настройки и состояние находятся вне document root. Архив загрузки также оставлять
только вне `public_html`. Не отдавать PHP как статический текст. Аккаунтные настройки
и серверы spoki.studio не изменять. `mail()` использует существующий почтовый транспорт
хостинга; покупка почтовых ящиков и SMTP-пароли не нужны.

Получатель фиксирован: `hunterjchinaski.work@gmail.com`; отправитель —
`site@hjcpit.com`. SPF должен разрешать реальные IPv4/IPv6 хостинга, без `a` для
GeoDNS/CDN. `Reply-To` добавляется только для корректного email посетителя.
Успех PHP mail означает приём транспортом, а не подтверждённую доставку во входящие.
Для проверки доставки необходимо письмо с разрешёнными тестовыми данными и
подтверждение получения либо журнал доставки хостинга.

GET выдаёт краткоживущий подписанный токен, привязанный к Origin/IP; POST принимает
JSON. Разрешены только `https://hjcpit.com` и `https://www.hjcpit.com`. Preview никогда
не отправляет запросы. Сервер проверяет длины и формат полей, согласие и его редакцию,
honeypot, лимиты частоты. Время ожидания клиента — 20 секунд. Поля сохраняются при ошибке.

Идентификатор запроса хранится клиентом в памяти до успеха/изменения данных. Повтор
не отправляет письмо второй раз. Сервер фиксирует pending до передачи письма;
неопределённый результат никогда автоматически не пересылается. В состоянии есть
только HMAC-производные, счётчики и квитанции, без имени/контакта/текста. Квитанции
устаревают через 7 дней, счётчики через сутки; очистка происходит при запросах.
Отдельно остаются почтовая очередь/переписка и журналы инфраструктуры.

Проверки без писем и сети:

```sh
php scripts/form-test.php
node scripts/form-client-test.cjs
python3 scripts/check-site.py
```

Локально/на Pages форма демонстрационная. Не ослаблять проверку hostname для теста
и не добавлять preview-origin на сервер. Внешний тест отправлять только с разрешения
пользователя; после неопределённого результата повторять прежний requestId.

Для отключения отправки установить `enabled => false` в закрытом `config.php`.
Страницы продолжат показывать честную ошибку и контактную почту.
Не менять ключ `state/key.json` и не удалять квитанции при обычном обновлении.
