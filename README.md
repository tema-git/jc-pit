Тестовый адрес: [JC Pit](https://tema-git.github.io/jc-pit/). [Репозиторий tema-git/jc-pit](https://github.com/tema-git/jc-pit); GitHub Pages публикует ветку main из корня. ## Текущее направление

27.10.2026 пользователь попросил сделать макет как в существующей Tilda, добавив smooth, анимацию и интерактив. Основа композиции: лесной DIVE IN → CHOICE с фирменным знаком и двумя фото → отдельные CATALOG и ARCHIVE. Цветные исходные фотографии остаются на чёрном фоне. По последнему уточнению весь текст, включая заголовки, меню, формы, кнопки, галереи и подвал, использует только локальный Source Code Pro. Предыдущая редакционная одностраничная версия с огромным Instrument Serif и светлой сеткой не задаёт текущий макет.

Правки 28.10.2026 имеют приоритет над прежним буквальным повторением Tilda. В каталоге изображение изделия стало доступной кнопкой открытия подробностей; название и год остались текстом, отдельные «Подробнее» и «Сделать заказ» под каждым изделием удалены. В диалоге действие «Обсудить модель» ведёт к общей форме. Архив — вступительный текст, затем единая сетка 58 уникальных реальных фотографий со случайным порядком при загрузке и полноэкранным просмотром, без категорий и модельных карточек.

Пользователь отдельно попросил убрать блок «Рассмотреть детали». Он удалён целиком; ракурсы остаются в диалогах каталога. Не добавлять вместо него мини-игру или другой отдельный виджет. Это исключение для текущего JC Pit; постоянное правило отдельного интерактивного блока для будущих сайтов не отменено.

Сохраняются закреплённая шапка и заметные «Контакты» на телефоне, серебряные главные действия, реакции на курсор и скролл, reduced motion. Последнее уточнение делает серебряное выделение ярче и металлически выразительнее: `#f6f8fb` на чёрном, `#303943` на серебряных и светлых кнопках, `background:transparent`, `text-shadow:none`. Над всем обычным выделяемым текстом — стандартный I-beam; уменьшенный крест с короной остаётся на фоне, фотографиях, ссылках и кнопках. Это локальные изменения JC Pit; глобальные предпочтения не меняются.

Ряды каталога поддерживают нативный свайп, кнопки и клавиатуру; изделия открываются в диалогах с галереями. Все стрелки и служебные иконки — SVG или CSS, без Unicode-глифов и эмодзи, чтобы iOS не превращала их в цветные значки. Стрелки главных действий исходно направлены вверх-вправо, при hover/focus — вправо; скролл их не вращает. Для навигации фото явно разрешены естественные SVG-стрелки влево / вправо. Нажатие открытого фото переключает на следующий снимок; соседние кадры предварительно загружаются, ожидание видно, старый кадр скрывается до готовности нового.

Переход DIVE IN → CHOICE прогревается заранее, без предварительной загрузки всех галерей. Текущая версия общих ресурсов — `20261028-refine2`; при публикации проверять одинаковые актуальные URL на всех четырёх страницах.

На первом экране каталога нет «Смотреть изделия». Вступительная архивная фраза «Это могут быть как экспериментальные проекты, так и индивидуальные заказы клиентов.» занимает одну строку на широком экране, а на телефоне свободно переносится с читаемым текстом около 18 px, без горизонтального переполнения.

Форма демонстрационная: данные не отправляются, заказ не создаётся. Введённые значения не сохраняются в localStorage, cookies или на сервере; после успешной локальной проверки личные поля очищаются. Реальное обращение доступно через `mailto:` — письмо отправляет сам посетитель. Не подключать обработчик и сохранение данных без отдельного запроса.

## Запуск локально

Открывать через HTTP, поскольку подробности изделий загружаются из JSON. `file://` не подходит для полноценной проверки.

Из папки проекта, при наличии Python 3:

```sh
python3 -m http.server 4173
```

Открыть [http://localhost:4173/](http://localhost:4173/). Подойдёт любой статический HTTP-сервер с корнем в этой папке; установка пакетов не требуется.

| `assets/` | Оптимизированные фотографии, знак, фильм, курсоры и локальные шрифты с лицензиями |

Все локальные URL относительные: сайт опубликован в подпапке `/jc-pit/`. Не менять их на `/assets/...` без отдельной настройки размещения. Карточки в HTML и записи JSON связаны по `data-product` / `id`; при изменении изделия синхронизировать id и опции формы.

Каталог содержит 10 моделей: `zip-2026`, `shoes-2026`, `wholecut-2025`, `high-2025`, `boots-2025`, `shoes-2025`, `duffel`, `gloves`, `wallet`, `dice`. Их категории — `shoes` и `objects`. Раздел одежды каталога воспроизводит сообщение оригинала; вымышленные карточки туда не добавляются. Ещё 13 исторических архивных записей с id `archive-…` сохраняют исходное соответствие фотографий; их категории больше не отображаются как разделы сайта. Точное происхождение хранится в materials.

Архивная сетка находится прямо в HTML: нативные кнопки `data-archive-photo`, отдельного photo JSON нет. Из 64 ссылок в модельных записях получены 58 уникальных фотографий с устранением повторов по пути и SHA-256. Порядок перемешивается при загрузке и затем остаётся одинаковым в сетке и полноэкранном просмотре. Открытие, листание и закрытие не должны менять его заново.
